Save this configuration

Writes a complete design file under designs/, with your changes applied and marked as yours. It can be reopened here or run from the command line.

My library: your own propellants and tank materials

An entry added here appears in the fuel, oxidiser and material dropdowns of every design, marked "(my library)". A design saved with it carries a copy, so it still opens on another computer.

Analyses to run

Each one adds a tab and a section to the report. Anything an analysis depends on is run with it, so ticking the shell stress also flies the trajectory and builds the load cases.
